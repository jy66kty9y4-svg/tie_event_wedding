# Canonical tags

Use at most seven tags per card. Reuse these prefixes; do not create near-duplicates.

| Tag family | Use |
| --- | --- |
| `domain/<name>` | Product or business area |
| `layer/frontend`, `layer/backend`, `layer/data`, `layer/infra` | Technical layer |
| `capability/<name>` | User-visible capability |
| `risk/low`, `risk/medium`, `risk/high` | Change risk |
| `status/draft`, `status/in-progress`, `status/review`, `status/done`, `status/blocked` | Task state |
| `task/research`, `task/implementation`, `task/review` | Work type |
| `knowledge/index`, `knowledge/component`, `knowledge/decision` | Note role |

Search a nested tag first, for example `tag:#domain/auth`, then open only linked notes.
