# Пять фавиконов TIE

Бордовый фон #7B1F35, белая надпись #FFFFFF.

1. Фирменная рукописная подпись TIE.
2. Рукописная T из оригинального знака.
3. TIE фирменным шрифтом Ardeco.
4. Монограмма T фирменным шрифтом Ardeco.
5. TIE фирменным шрифтом Evolventa Bold.

Каждый вариант содержит SVG с контурами, PNG 16/32/48/64/180/192/256/512 px и ICO 16/32/48 px. SVG не зависит от установленных шрифтов. Превью показывает крупную иконку и реальные размеры 32 и 16 px.

Рукописный знак взят из векторного оригинала, предоставленного владельцем бренда. Типографические варианты используют локальные Ardeco (SIL OFL) и Evolventa (LPPL); тексты лицензий находятся в licenses. Betmo не используется. Варианты подготовлены отдельно; фавикон действующего сайта не заменён.
