# TIE cabinet brand resources

Official supplied artwork, exported for RGB web display. Only transparent
margins and output dimensions were changed; the drawing and colors are intact.

- `logo-dark.png`: Логотип_Осн_Печать-12.png, transparent black/red version.
- `logo-light.png`: Логотип_Осн_Печать-10.png, transparent white/red version.
- `signature-red.png` and application icons: Элементы-11.png.
- `signature-light.png`: Элементы-07.png.
- `event-pattern.png`: Элементы-15.png.

Originals were supplied in `Логотип_TIE` and `Элементы_TIE` in Downloads.

The four Evolventa faces and Ardeco were converted to WOFF from the supplied
font files without subsetting. Their copyright and redistribution licenses
are included beside the fonts. Evolventa uses the supplied LPPL option;
Ardeco uses the supplied SIL Open Font License.

Betmo's supplied license document identifies Personal Use. Its font binary
is not redistributed. The official supplied signature artwork provides the
brand's decorative lettering; no new Betmo lettering is generated.

All fonts and artwork are local resources, with no third-party font service.
