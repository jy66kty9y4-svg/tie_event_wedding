Источники прочитаны локально 08.09.2026. Действующие продукты не изменяются.

Содержимое исходников предметно связано с университетом; копирование экранов целиком перенесло бы чужие сущности и общий финансовый доступ. Переиспользуются проверенные взаимодействия и небольшие утилиты с атрибуцией, новые доменные модули реализованы отдельно. React и SQLite сохранены, статическая React-сборка Vite и небольшой Node HTTP API позволяют открывать один и тот же интерфейс без сети.

## Модель

Agencies → users / roles / grants / projects. Назначение объединяет роль и область действия в одной записи. Токен сессии не хранит привилегии. Entities принадлежат агентству и, при необходимости, проекту. Каждая запись имеет стабильный ID, версию, признак удаления и историю. Таблицы и разделы имеют собственные версии; команды изменения строк проверяют версию схемы.

Смета = obligations. Согласованные цены живут в обязательствах, проектный подрядчик ссылается на обязательство. Общий каталог отдельно. Movements — единый журнал, из которого считаются остатки у организаторов, оплаченные обязательства и собственный бюджет агентства. Гонорар — одно событие в двух представлениях. Идемпотентность по пользователю и ID команды, с проверкой неизменности тела. Версия обязательства блокирует две независимые отметки полного расчёта.

## Последовательность

1. Схема, права, сессии, заявки и приглашения.
2. Гибкие таблицы, шаблоны, подрядчики, два финансовых контура.
3. Полный интерфейс и офлайн-очередь.
4. Серверные сценарии, браузер, мобильный режим и проверка без сети.

## Проверка Excel

Проверены названия и видимость всех листов и формулы B135:E135. B135 заканчивается строкой 134, C135:E135 — строкой 133. Личные значения не импортируются. Смета в приложении суммирует текущие записи по ID, без фиксированных диапазонов. Демонстрационные данные создаются отдельной командой, все имена вымышлены.

## Визуальная система

Фон #f7f8fa, поверхность #ffffff, текст #292632, акцент #665269, дополнительный #eae4ef, успех #417967. Заголовки Georgia, текст system sans-serif, суммы с tabular-nums. Публичная страница построена вокруг типографики и пересекающихся контуров обручальных колец. Кабинет — постоянная навигация, компактная сводка и рабочая таблица. На телефоне навигация сворачивается, формы превращаются в полноширинные панели, первая колонка таблицы закреплена.
