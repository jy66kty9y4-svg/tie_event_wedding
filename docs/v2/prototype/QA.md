# Проверка визуального прототипа

Дата: 9 сентября 2026. Проверялся локальный `prototype.html`, а не рабочее приложение.

## Проверки

| Проверка | Результат |
|---|---|
| Загрузка 45 маршрутов при 1440 × 1000 | 45/45 открываются, без пустого приложения |
| Загрузка 45 маршрутов при 390 × 844 | 45/45 открываются, без общего горизонтального переполнения |
| Изображения на этих страницах | Нет неуспешно загруженных изображений |
| Консоль браузера | Ошибки и предупреждения приложения не обнаружены |
| Синтаксис 7 файлов JS | Пройден |
| Генерация HTML: 45 маршрутов × 3 состояния × 3 проекта | 405 комбинаций без исключений |
| Ссылки на экраны и зарегистрированные действия в HTML | Неизвестных маршрутов/обработчиков не найдено |
| Whitespace diff | Пройден |

## Пройденные сценарии в браузере

- Карта экранов, переходы по боковому меню и вкладкам, мобильное открытие меню.
- Переключение наполненного и пустого плана, выбор роли пары и возврат к организатору.
- Создание задачи, открытие её карточки, изменение статуса, возврат и поиск по названию.
- Утверждение варианта согласования: комментарий в истории, состояние «Принято» и кнопка «Вариант утверждён».
- Публичная заявка: обязательные поля, заполнение, экран подтверждения.
- RSVP: выбор ответа, питания и трансфера, переход к подтверждению.
- Открытие приглашения из карточки гостя: имя сохраняется в персональном обращении.
- Вход в макет с ролью пары открывает обзор свадьбы с навигацией пары.
- Изменение заголовка в редакторе, сохранение, отображение на публичной главной.
- Открытие оформленной папки дня в диалоге.

## Визуально просмотрены

Обзор агентства, рассадка, варианты согласования, публичная главная на компьютере и телефоне, мобильная заявка, ответ гостя, мобильный план, форма задачи и печатное представление. Фото загружены локально и просмотрены отдельно. Для декора выбран спокойный вариант со светлой сервировкой.

В ходе проверки исправлены: поля публичных контейнеров, размер логотипа, растянутый мобильный список задач, двойной значок поиска, первичные кнопки, неактуальные выбранные карточки, переходы в детали без предварительного выбора, несовпадающее имя приглашённого, переполнение мест за столами, суммы в смете, редактор без изменения страницы и состояние после утверждения.

## Ограничения

Это проверка визуального прототипа. Настоящая авторизация, API, серверное сохранение, доставка приглашений, файловое хранилище и финансовые операции не выполняются. Проверка HTML во всех комбинациях не равна ручной приёмке каждой формы; основные перечисленные сценарии пройдены отдельно. Браузерная печать подготовлена стилями; отправка на физический принтер не выполнялась.
