# Исправления по комментариям к локальному приложению

Дата: 9 сентября 2026. Предпросмотр: http://127.0.0.1:4188. Изменения внесены в приложение, публикации на рабочий сервер не было. Существующая временная база предпросмотра сохранена.

## Что изменено

1. Выбор стола не записывает координаты. Перетаскивание начинается после движения на 4 экранных пикселя, показывает положение во время движения и сохраняет его один раз при отпускании. Используются координаты всего плана, независимо от дочерних подписей, прокрутки и масштаба. Escape/pointercancel отменяют движение.
2. Зоны получили собственные интерактивные области: выбор, перетаскивание, свойства и удаление. Стрелки на клавиатуре перемещают выбранный объект; Shift увеличивает шаг.
3. Повторное массовое создание продолжает номера, пропускает занятые названия и размещает новые столы на свободных участках. При нехватке пространства сообщает, что уменьшить количество или увеличить зал. Размеры зала сохраняются отдельной кнопкой.
4. Вместимость 0 сохраняется во всех командах, не рисует стулья и не разрешает посадку гостей. Защита занятых мест при уменьшении вместимости сохранена. У указанного пользователем «Стола 7» в демонстрационном проекте восстановлено 0 мест.
5. Формы: круг, прямоугольник, овал, квадрат и собственный контур. В режиме рисования пользователь отмечает углы на плане, может убрать последнюю точку, завершить или перерисовать контур. Сервер проверяет 3–64 точки, ненулевую площадь, отсутствие пересечений и границы зала. Ширина/высота — от 40 см.
6. Отрисовка мест учитывает периметр выбранной формы. Экран, PNG и печать используют одну SVG-отрисовку. Исправлена подготовка PNG при действующей политике безопасности браузера; после генерации доступна явная ссылка «Скачать файл».
7. Логические поля рабочей таблицы переключаются без кнопки редактирования. Отправляется patch только одного поля; сохраняются права, версии, обработка ошибок и блокировка повторной отправки.
8. На доске плана задачи переносятся между статусами. Перенос в «Не требуется» открывает форму причины; серверные зависимости и ограничения сохраняются. Есть подсветка цели, пустые области сброса и состояние отправки. Смена статуса через диалог остаётся доступной.
9. Комментарии: компактное поле, отдельная обычная кнопка, состояния пустого списка/отправки/ошибки, карточки комментариев и локализованные даты. Стили работают внутри модального окна на компьютере и телефоне.
10. У блока проверки перед свадьбой исправлены размеры шрифтов и интервалы заголовка/подзаголовка; счётчики не используют неверные склонения.

## Проверка

- Полная регрессия: 85/85 тестов. После последней коррекции границ фигур и минимального размера — 21/21 тестов рассадки и взаимодействий. Vite build и diff check проходят.
- CUA, 1357×983: выбор без сдвига, перенос на 6 px без изменения Y, движение зоны, две последовательные группы по два стола с 0 мест, сохранение собственного контура и загрузка после обновления.
- При масштабе 150% перенос на 9 px соответствует тем же 6 px при 100%; исходное положение проверяемого стола восстановлено.
- Доска: фактический перенос `todo → doing`, открытие причины для `skipped`, отмена без смены статуса. Создание комментария и локализованная дата проверены в браузере.
- Тайминг: галочка сохранена без входа в редактирование, повторно прочитана после перехода и снята обратно.
- 390×844: рассадка, доска, таблица и модальное окно без горизонтального переполнения страницы. Доска прокручивается внутри своего контейнера; touch-перенос реализован, отдельное физическое touch-устройство не проверялось.
- PNG успешно создаётся и получает ссылку на файл; завершение загрузки в системную папку встроенный браузер инструменту не подтвердил.
- Ошибок JavaScript при окончательной проверке не обнаружено. Для проверки форм в локальном проекте оставлены четыре стола без мест и нарисованный стол для торта.
