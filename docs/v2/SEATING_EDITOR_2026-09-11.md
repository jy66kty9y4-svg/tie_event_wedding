| Комментарий | Изменение |
|---|---|
| 1. Выделять выбранный режим | «Сразу несколько», добавление зоны и рисование имеют розовое активное состояние и aria-pressed. |
| 2. Начальный номер автоматически | Вычисляется после последнего номера выбранного префикса, обновляется после создания/изменения списка; поле доступно для чтения. Повторные пакеты продолжают нумерацию. |
| 3. Настраивать и рисовать зоны | Прямоугольная, овальная и произвольная формы. Название, ширина, высота, поворот; существующий произвольный контур можно редактировать. Геометрия сохраняется на сервере и включается в экспорт. |
| 4. Переименование двойным кликом | Поле появляется прямо в зоне. Enter или потеря фокуса сохраняет, Escape отменяет. Отдельного окна нет. |
| 5. Поля накладываются | Ограничены ширины инпутов и колонок; исправлены внутренние отступы. На компьютере боковая панель закреплена и прокручивается самостоятельно. |
| 6. Нельзя стереть ноль, нет изменения размера | Поля хранят редактируемый текст. Можно очистить значение, затем ввести новое; пустое не заменяется нулём. Валидный размер сразу меняет SVG и область выбора пропорционально метрам плана. Сохранение проверяет числовые данные. |
| 7. Перемещение и удаление точек | Точки подсвечиваются при наведении/выборе, перемещаются мышью с захватом указателя. Боковая панель показывает выбранную точку и «Удалить точку»; Backspace/Delete удаляют её вне текстовых полей. |
| 8. Замыкание контура | До нажатия на первую точку отображается открытая ломаная без заливки и замыкающего сегмента. Сохранение доступно после замыкания. Если после удаления осталось меньше трёх точек, контур снова открывается. |
| 9. Настройки стола и посадка | Свойства выбранного стола расположены в начале панели. Показаны номера мест и занятость, выбор места связан с назначением гостя. Доступны количество мест, форма, размеры, положение. Для пустого реестра есть объяснение и ссылка на добавление гостей. |
