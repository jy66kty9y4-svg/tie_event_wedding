# Приёмка tie.event

## Обязательные сценарии

Результаты заполняются по фактически выполненным проверкам. Наличие интерфейса или service worker не считается проверкой поведения.

| Сценарий | Способ проверки |
|---|---|
| Публичная заявка, недоступность проекта до одобрения, ровно один проект после повтора | Серверный тест + регистрация/рассмотрение в браузере |
| Создание свадьбы организатором и два отдельных аккаунта пары | Серверные приглашения + браузерные сессии |
| Полное редактирование своей свадьбы парой, включая раздел и колонку | Серверный тест + UI формы |
| Изоляция агентств, чужих проектов, файлов и офлайн-выгрузок | Негативные API сценарии |
| Изменение роли в активной сессии и сочетание нескольких областей | Серверные регрессии |
| Устойчивая смета; различие неизвестной, включённой и нулевой стоимости | Точные числовые проверки |
| Поступление средств пары, частичная выплата, возврат и передача | Сверка остатков проекта, каждого держателя и агентства |
| Гонорар учитывается однократно; исправления, удаление и повтор доставки | Транзакционные регрессии |
| Общий прайс не перезаписывает договорённость свадьбы | Изменение каталога, затем проектного выбора |
| Единые записи гостей/рассадки и общих событий тайминга | Два представления одного ID |
| Офлайн после перезагрузки, локальная отметка и синхронизация | Браузер с отключённой сетью |
| Повтор доставки, два устройства, отзыв прав и изменение схемы | API и офлайн-конфликты |
| Компьютер и телефон: формы, меню, таблицы, ошибки, консоль | Chromium desktop и мобильный viewport |

## Материальные границы проверки

- Локальная проверка не является развёртыванием на сервере.
- Домен, почтовая доставка приглашений и окончательные материалы агентства владельцем ещё не выбраны. Приглашение выдаётся как ссылка для самостоятельной передачи.
- Синхронизация повторно проверяет права. Без сети устройство не может мгновенно узнать об отзыве роли. Выход очищает локальные приватные данные.
- Размещение в интернете потребует HTTPS для установки PWA и service worker; localhost разрешён браузером для разработки.
- Оригинальный XLSX используется для структуры процесса, не импортируется в рабочие или демонстрационные базы.

Фактические результаты и известные ограничения будут приведены в README и отчёте проверки после интеграции.
